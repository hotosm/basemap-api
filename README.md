# Basemap API

> [!WARNING]
>
> This project will be replaced with:
> https://github.com/hotosm/openaerialmap/issues/244

A web API microservice to generate basemap files from TMS sources.

Basemaps are generated in the following formats:

- MBTiles ✅
- PMTiles ✅
- OSMAnd  ✅  (sqlitedb)
